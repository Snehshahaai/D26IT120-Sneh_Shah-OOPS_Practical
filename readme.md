# Object-Oriented Programming (OOPS) Practical – Part A

## 📘 Overview

This repository contains the **Part A** programs of the Object-Oriented Programming (OOPS) practical course implemented in **Java**. These programs are designed to strengthen the understanding of fundamental OOP concepts through hands-on coding exercises.

---

## 🛠️ Technologies Used

* Java
* JDK 8 or above
* Object-Oriented Programming (OOP)

---

## 🎯 Learning Outcomes

After completing these practicals, you will be able to:

* Understand the principles of Object-Oriented Programming.
* Design classes using constructors and encapsulation.
* Implement constructor overloading and constructor chaining.
* Use `static` and `final` members effectively.
* Override `toString()`, `equals()`, and `hashCode()` methods.
* Compare Java objects based on their data.
* Detect duplicate objects using object comparison.
* Apply Java OOP concepts to practical programming problems.
